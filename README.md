# SN2I — Cartographie clients · aliments de bétail

Formulaire de terrain pour le recensement des clients de la vente d'aliments de bétail
(mil, maïs, tourteaux, mélanges SN2I) sur la zone **Dakar · Mbour · Thiès**.

**Adresse du formulaire** : https://aidara1950-beep.github.io/sn2i-cartographie/

## Ce que c'est

Un fichier HTML unique, sans dépendance externe, sans serveur, sans base de données.

- Fonctionne **hors ligne** : les fiches restent sur le téléphone de l'enquêteur.
- Prend la **photo de devanture** et la **position GPS**.
- Saisit les quantités vendues **en kilogrammes par mois**, par produit.
- **Exporte** une archive ZIP contenant un classeur Excel des fiches, les photos et une synthèse,
  à envoyer par WhatsApp.
- Fonctionne sur Android comme sur iPhone ; peut être ajouté à l'écran d'accueil.

## Contenu de ce dépôt

| Fichier | Rôle |
|---|---|
| `index.html` | Le formulaire complet (HTML + CSS + JavaScript, tout inclus). |

## Avertissement

Ce dépôt est **public**. Il ne doit contenir **aucune donnée client** — ni nom, ni numéro de
téléphone, ni photo, ni position. Le formulaire n'envoie rien vers ce dépôt : les fiches saisies
restent sur l'appareil de l'enquêteur jusqu'à l'export manuel.

La collecte est volontairement **décentralisée** : chaque enquêteur conserve ses fiches et les
transmet à la direction par un canal interne.
